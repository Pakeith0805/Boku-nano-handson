# src/nlg/

承認済み言い回し（`phrases/ja_phrases_v1.yaml`）を1文に組み立てるための、日本語の
表層処理。opの意味やop列の妥当性は持たない——それは`src/semantics/`と`src/interp/`の役目。
ここにあるのは活用変換だけ。

## conjugate.py

終止形の言い回しを連用形に変換する。`ja_phrases_v1.yaml`は全て終止形（言い切り）で
査読・凍結してあるため（[[ja-sentence-frame]]決定の「まず終止形のまま査読」段階）、
複数opを連用形連結（C方式）で1文にまとめる際はここを通す。

### 定数

| 名前 | 説明 |
| --- | --- |
| `RULES` | 語尾→連用形の変換規則。長い語尾から順に並んでいる（`える`より先に`る`だけでは見ない） |

### 関数

| 関数 | 説明 |
| --- | --- |
| `to_renyou(phrase)` | 終止形の言い回しを連用形に変換する。`RULES`のどれにも合わない語尾は`ValueError` |
